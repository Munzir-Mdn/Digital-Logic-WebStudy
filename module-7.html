1. Sequential vs Combinational

Combinational

Output depends on the input, has no memory element, and cannot memorize the previous output.

Sequential

Has a memory element. Output depends on the input and previous output from feedback elements.

2. Latch vs Flip-Flop

LatchFlip-Flop
Temporary bi-stable storage deviceSynchronous bi-stable storage device storing one bit
Level-sensitiveEdge-triggered
S-R, Gated S-R, Gated DS-R, J-K, D, T
Rising edge = positive edge. Falling edge = negative edge.

3. S-R & Gated S-R Latch

For the active-HIGH S-R behavior described in the slides: Set makes Q=1; Reset makes Q=0; both 0 preserve the previous state; the same-state output condition is invalid.

4. Gated D Latch

00/1No Change

Slide rule: EN=1 → Q=D. EN=0 → latch is off.

5. Flip-Flops

S-R

Changes at the specified clock transition; S=R=1 is invalid.

J-K

Versatile FF. Unlike S-R, J-K has no invalid state; J=K=1 toggles.

D

Stores one data bit. Q follows D at the active clock edge.

T

Toggle flip-flop, frequently used in counters.

6. PRE, CLR & Master-Slave JK

The module gives asynchronous PRE/CLR the highest priority, clock medium priority, and synchronous S-R/J-K/D/T inputs the lowest priority.

Master-Slave JK has two sections: the master receives the external JK inputs; the slave receives the master outputs and uses an inverted clock pulse.

Timing Diagram Method

  1. Write the initial Q first.
  2. Identify whether the device is a latch or flip-flop.
  3. For a latch, check the active input/EN level throughout the interval.
  4. For a flip-flop, mark only the specified rising or falling clock edges.
  5. At each valid point, read S/R, J/K, D or T.
  6. Apply the truth table and carry Q forward until the next valid change.
  7. Q̄ is the complement of Q where the state is valid.
Key distinction from Exercise 7.3: the Gated S-R latch can respond while EN is active, whereas the positive-edge flip-flop responds at its triggering clock edges.
