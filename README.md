# SECR1013 Digital Logic — Unified Web Study

All module HTML pages are combined under one landing page (`index.html`).

## Structure
- `index.html` — module dashboard
- `modules/` — Module 1 through Module 9 pages
- `assets/` — CSS, JavaScript and images required by interactive modules

## GitHub Pages
Upload the CONTENTS of this folder to the repository root.
Then use: Settings → Pages → Deploy from a branch → `main` → `/ (root)`.

Do not upload the ZIP itself as the website root; extract it first.
