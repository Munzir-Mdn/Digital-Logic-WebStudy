# SECR1013 Digital Logic — Interactive WebStudy

An interactive web-based study platform for **SECR1013 Digital Logic**, designed to make Digital Logic concepts easier to understand through structured notes, interactive simulations, flashcards, quizzes, and exam-focused revision.

🌐 **Live WebStudy:**  
[Open Digital Logic WebStudy](https://munzir-mdn.github.io/Digital-Logic-WebStudy/?utm_source=chatgpt.com)

## ✨ Features

- 📖 Structured study notes
- 🧠 80/20 exam revision
- 🃏 Interactive flashcards
- 📝 Mini quizzes / Exam Mode
- ⚡ Interactive Digital Logic simulators
- 🔢 Counter simulations
- ↔️ Shift-register simulations
- 📊 Progress tracking using browser LocalStorage
- 🔎 Module search from the main dashboard
- 📱 Responsive layout
- 🌐 Fully deployable using GitHub Pages
- 🚫 No backend, database, API, or installation required

## 🧪 Interactive Topics

The later modules include interactive learning tools for concepts such as **JK/D/T flip-flops, asynchronous and synchronous counters, UP/DOWN counters, BCD decade counters, cascaded counters, SISO/SIPO/PISO/PIPO shift registers, Ring Counters, and Johnson Counters**.

## 🚀 Run Locally

Clone the repository:

```bash
git clone https://github.com/munzir-mdn/Digital-Logic-WebStudy.git
cd Digital-Logic-WebStudy
```

Then open:

```text
index.html
```

in any modern web browser.

No installation or build process is required.

## 🎯 Project Goal

The goal of this project is to transform traditional Digital Logic lecture material into an interactive learning environment.

Instead of relying only on static notes, students can:

```text
LEARN
  ↓
VISUALIZE
  ↓
INTERACT
  ↓
PRACTICE
  ↓
QUIZ
  ↓
REVISE
```

This approach is intended to make concepts such as Boolean logic, flip-flops, counters, and shift registers easier to study and revise.
