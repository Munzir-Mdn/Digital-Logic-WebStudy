# SECR1013 Digital Logic Interactive Web Study

Static HTML/CSS/JavaScript study website designed for GitHub Pages.

## Run locally
Open `index.html` in a browser.

## Publish with GitHub Pages
1. Create a GitHub repository.
2. Upload all files and folders from this project.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Select `main` and `/ (root)`, then Save.

## Current content
- Module 7 — Latches & Flip-Flops
- Interactive J-K, D and T flip-flop labs
- Flashcards
- Quiz / Exam Mode
- Browser-local progress tracking
- Visual cheat sheet

No backend, API, framework, or database is required.
