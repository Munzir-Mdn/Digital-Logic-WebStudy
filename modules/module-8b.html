3-bit UP JK design from the module: J0=K0=1; J1=K1=Q0; J2=K2=Q1Q0. Thus Q0 toggles every clock, Q1 toggles when Q0=1, and Q2 toggles when Q1Q0=11.

4. 2-bit UP/DOWN with D Flip-Flops

The module defines one example with control input X: X=0 → UP and X=1 → DOWN. It later gives:

D1 = X ⊕ Q1 ⊕ Q0
D0 = Q̅0

When solving a design question, preserve the X convention given by that specific question; later exercises in the slides also use the opposite X convention.

5. Arbitrary Sequences

The worked arbitrary-sequence example is a 3-bit counter using T flip-flops. It uses only four valid states: 001 → 010 → 101 → 111 → 001. The remaining states 000, 011, 100 and 110 are treated as invalid / don't-care states in that design.

6. Synchronous BCD Decade Counter

The module's BCD decade counter counts 0–9 and then recycles to 0. Four flip-flops are required; unused states 10–15 are taken as don't-care terms.

7. Cascaded Counter / Frequency Divider

The module states that cascading connects the last-stage output of one counter to the input of the next. The total modulus is the product of the stage moduli.

Example: MOD-4 × MOD-8 = MOD-32.
The slides also show two decade counters → MOD-100 and three decade counters → MOD-1000 frequency division.

8. Analysis of Sequential Circuits

The module reverses the design process when a logic schematic is already given:

  1. Derive excitation equations from the schematic.
  2. Insert them into the flip-flop characteristic equations to derive next-state/output equations.
  3. Generate next-state/output tables and the state diagram.
  4. Develop a timing diagram and verify through simulation.
In the module's Modulo-4 example using D flip-flops, Q+ = D. The analysis concludes it is a 2-bit synchronous MOD-4 counter with a common clock; Cnt=1 counts up and Cnt=0 holds the previous state.
