1. Shift Register Fundamentals

A shift register stores binary data using an arrangement of flip-flops. Stored data can be shifted left or right when the required signal is applied. The module emphasizes two major uses in digital systems: data storage and data transfer/movement.

Each flip-flop stores 1 bit; therefore more bits require more flip-flops.

2. Four Basic Data-Movement Types

SISO

Serial In / Serial Out

One input bit per clock and serial output.

SIPO

Serial In / Parallel Out

Bits enter serially; outputs are read simultaneously.

PISO

Parallel In / Serial Out

Inputs load together and then shift out one bit at a time.

PIPO

Parallel In / Parallel Out

Input and output are both parallel.

3. Serial Shift-Register Characteristics

A serial shift register is a chain of flip-flops connected in cascade. Its operation is synchronous because the flip-flops use a common clock. A register shifts data one bit at a time.

For an n-bit SISO in the module: n clock cycles are required to shift all data in, then another n cycles to shift all data out.

5. PISO — Parallel In / Serial Out

The module uses SHIFT/LOAD': LOW loads parallel inputs; HIGH shifts the data. The MSB appears at the last-stage output Q(n−1).

Module example: for D0D1D2D3 = 1010, LOAD places 1010 into Q0…Q3, then each SHIFT moves the data toward Q3/serial output.

6. PIPO — Parallel In / Parallel Out

Inputs and outputs are parallel. The module notes that the parallel data does not appear immediately at the output; the output appears at the positive clock edge.

The 4-bit device example in the slides can perform PIPO, PISO, SIPO and SISO. Its SH/LD control loads when LOW and shifts when HIGH.

7. Ring Counter Simulator

A ring counter is a SISO-type shift register whose final output is fed back to the first input. The module states that an n-bit ring counter = MOD-n.

The '1' is retained and moves around the ring at each clock pulse.

8. Johnson Counter Simulator

In the Johnson counter, the complement of the last output is fed back into the first flip-flop. According to the module, the number of unique states is twice the number of stages: n-bit = MOD-2n.

For 4 bits, the module's summary sequence is: 1000 → 1100 → 1110 → 1111 → 0111 → 0011 → 0001 → 0000 (then repeats, depending on the stated starting point).
