Module 2a — Number Systems

1. Chapter Overview

This module introduces positional number systems and conversion among decimal, binary, octal and hexadecimal numbers, including whole-number and fractional conversions.

Main idea: A number's value depends on its base/radix, its allowed digits, and the positional weight of each digit.

2. Number Systems at a Glance

SystemBaseDigits / Symbols
Binary20, 1
Octal80–7
Decimal100–9
Hexadecimal160–9, A–F

For base B, the permitted digits range from 0 to B−1. Positional notation expands a number as a sum of each digit multiplied by a power of the base.

3. Essential Terminology

  • Base / radix: the base of the numbering system.
  • Integer part: digits to the left of the radix point.
  • Fraction part: digits to the right of the radix point.
  • Most significant digit/bit (MSD/MSB): highest positional significance.
  • Least significant digit/bit (LSD/LSB): lowest positional significance.

4. Positional Value Method — Any Base → Decimal

Rule: Multiply every digit by its corresponding base power, then add all values.

General pattern: ... c₂B² + c₁B¹ + c₀B⁰ + c₋₁B⁻¹ + c₋₂B⁻² ...

Binary example from the module:
110100.011₂ = 32 + 16 + 4 + 0.25 + 0.125 = 52.375₁₀

Octal: weights use powers of 8. Hexadecimal: weights use powers of 16, with A–F representing hexadecimal symbols.

5. Decimal Whole Number → Another Base

Successive Division

  1. Divide the decimal whole number by the required base.
  2. Record the remainder.
  3. Divide the quotient again by the same base.
  4. Repeat until the quotient becomes 0.
  5. Read the remainders from bottom to top.
Example: 82₁₀ → base 8. Remainders are read bottom-up to obtain 122₈.

6. Decimal Fraction → Another Base

Successive Multiplication

  1. Multiply the fraction by the required base.
  2. Separate the resulting whole part from the new fraction.
  3. Repeat using the new fractional part.
  4. Stop when the fraction becomes 0 or the required precision is reached.
  5. Read the whole-number results from top to bottom.
Module example: 0.3125₁₀ = 0.0101₂.

7. Whole + Fraction Conversion

Treat the two parts separately:

PartDecimal → Other Base
Whole / integerSuccessive division
FractionSuccessive multiplication
Suggested memory aid: D↓, M↓ — Division answers are collected bottom-to-top; Multiplication integer results are collected top-to-bottom.

8. Binary ↔ Octal / Hexadecimal Shortcut

ConversionGrouping RuleReason shown in module
Binary ↔ Octal3 bits per octal digit2³ = 8
Binary ↔ Hexadecimal4 bits per hex digit2⁴ = 16

For a binary whole number, grouping starts from the radix point toward the left. For a binary fraction, grouping starts from the radix point toward the right. Add zeros when needed to complete the outermost group.

To convert octal or hexadecimal to binary, convert each source digit into its corresponding 3-bit or 4-bit binary group. The module recommends binary as an intermediate representation when converting octal ↔ hexadecimal.

9. Quick Recall

BASE → DIGITS → WEIGHTS → CONVERT
Binary: 2 → 0–1 → powers of 2
Octal: 8 → 0–7 → powers of 8
Decimal: 10 → 0–9 → powers of 10
Hex: 16 → 0–9, A–F → powers of 16

10. Common Mistakes

  • Using a digit that is invalid for the stated base.
  • Forgetting that fractional positions use negative powers such as B⁻¹ and B⁻².
  • Reading successive-division remainders in the wrong direction.
  • Mixing the whole-number and fractional conversion procedures.
  • Grouping binary into 4 bits for octal or 3 bits for hexadecimal—the correct grouping is octal = 3, hexadecimal = 4.
  • Grouping fractional binary from the wrong direction; start at the radix point and move right.

11. Study Priorities

  1. Memorize bases and valid symbols.
  2. Understand positional weights before memorizing conversion procedures.
  3. Master any-base → decimal using positional expansion.
  4. Master decimal whole → base using successive division.
  5. Master decimal fraction → base using successive multiplication.
  6. Practice 3-bit octal and 4-bit hexadecimal grouping until automatic.

12. Practice Questions + Model Answers

Q1. Express 567.23₁₀ as positional values.

Answer: 5×10² + 6×10¹ + 7×10⁰ + 2×10⁻¹ + 3×10⁻².

Q2. Convert 110100.011₂ to decimal.

Answer: 32 + 16 + 4 + 0.25 + 0.125 = 52.375₁₀.

Q3. Convert 42₁₀ to binary using successive division.

Answer: 101010₂.

Q4. Convert 0.3125₁₀ to binary.

Answer: 0.0101₂.

Q5. How many binary bits correspond to one octal digit and one hexadecimal digit?

Answer: Octal = 3 bits; hexadecimal = 4 bits.

Q6. Convert AF90.7B₁₆ to binary.

Answer: A=1010, F=1111, 9=1001, 0=0000, 7=0111, B=1011 → 1010111110010000.01111011₂.

Q7. Convert 45.27₈ to binary.

Answer: 4=100, 5=101, 2=010, 7=111 → 100101.010111₂.

13. Final Exam Recap

Any base → Decimal: positional powers.
Decimal whole → Base: successive division.
Decimal fraction → Base: successive multiplication.
Binary ↔ Octal: groups of 3.
Binary ↔ Hex: groups of 4.
Octal ↔ Hex: use binary as the intermediate representation.
