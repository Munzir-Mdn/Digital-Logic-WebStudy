SECR1013 Digital Logic — Module 2c: Arithmetic Operations

1. Chapter Overview

This module covers integer representation, unsigned and signed numbers, sign-magnitude, one's complement, two's complement, binary addition and subtraction.

2. Integer Representation

Main structure: Integer → unsigned or signed. Signed representations covered are sign-magnitude, one's complement and two's complement.

4. Signed Numbers

The module uses the MSB as a sign indicator: 0 = positive, 1 = negative. It then introduces three signed-number representations.

5. Sign-Magnitude

The sign bit is separated from the magnitude. A negative number keeps the same magnitude bits as the corresponding positive number but changes the sign bit from 0 to 1.

8-bit example: +25 = 00011001; −25 = 10011001.

6. One's Complement

Positive numbers are represented as in positive sign-magnitude. To form a negative number, complement every bit of the corresponding positive representation: 0 → 1 and 1 → 0.

+25 = 00011001
−25 in 1's complement = 11100110

7. Two's Complement

The process shown in the module is:

  1. Start with the positive binary representation.
  2. Convert it to one's complement.
  3. Add 1.
+25 = 00011001
1's complement = 11100110
+1 → −25 in 2's complement = 11100111
Suggested memory aid: “2's = Flip + 1.”

The module then applies addition using fixed-width 2's-complement representation, including examples such as +127 + 74 and 60 + (−30).

10. Binary Subtraction

The slides state that subtraction in a digital system is performed using 2's complement and addition. The carry from the MSB (signed bit) is deleted.

Core procedure: A − B = A + (2's complement of B), using the specified bit width.

11. Worked Exercise — Source Exercise 2c.1

Determine the decimal value of 10010101 expressed in sign-magnitude.

Answer: MSB = 1, so it is negative. Magnitude = 0010101₂ = 21₁₀. Therefore the value is −21.

13. Practice

Q1. What is the unsigned range for 10 bits?

Answer: 0 to 2¹⁰−1 = 0 to 1023.

Q2. Represent −25 using 8-bit sign-magnitude.

Answer: 10011001.

Q3. Represent −25 using 8-bit 1's complement.

Answer: +25 = 00011001 → invert → 11100110.

Q4. Represent −25 using 8-bit 2's complement.

Answer: 00011001 → 11100110 → +1 = 11100111.

Q5. Perform 24 − 17 using 6-bit 2's complement.

Answer: 24 = 011000; 17 = 010001; 2's complement of 17 = 101111. 011000 + 101111 = 1 000111. Delete the carry → 000111₂ = 7₁₀.

Q6. Perform −9 − 15 using 6-bit 2's complement.

Answer: −9 = 110111; −15 = 110001. Addition gives 1 101000; delete the carry → 101000₂, representing −24.

14. Common Mistakes

  • Forgetting the fixed bit width before forming complements.
  • Treating sign-magnitude as though all bits form the magnitude.
  • Stopping after bit inversion when the question asks for 2's complement—remember to add 1.
  • Using ordinary subtraction when the module asks for 2's-complement subtraction.
  • Forgetting to discard the carry from the MSB in the subtraction procedure shown in the slides.

15. Final Exam Recap

Unsigned: 0 → 2ⁿ−1
Signed MSB: 0 positive, 1 negative
Sign-magnitude: sign + magnitude
1's complement: flip bits
2's complement: flip bits + 1
Subtraction: add the 2's complement and discard the specified MSB carry
