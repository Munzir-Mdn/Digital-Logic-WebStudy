5. DeMorgan's Theorems

TheoremRuleMeaning
Ioverline(XY) = X̄ + ȲComplement of a product → sum of complements.
IIoverline(X + Y) = X̄ȲComplement of a sum → product of complements.
Extended forms shown in the module:
overline(XYZ) = X̄ + Ȳ + Z̄
overline(X + Y + Z) = X̄ȲZ̄
Suggested exam mnemonic: “Break the bar, change the operator.” When a complement bar is broken across a group, AND ↔ OR and each variable is complemented.

6. Why DeMorgan Matters

The slides connect DeMorgan's theorems to reducing the variety/number of logic-gate ICs and mathematically verifying the relationships NAND ≡ negative-OR and NOR ≡ negative-AND.

7. Three Equivalent Representations

Boolean Expression ⇄ Truth Table ⇄ Logic Circuit

A major part of this module is learning to move correctly between these representations.

8. Boolean Expression → Logic Circuit

The module says to treat the Boolean expression like a normal mathematical expression and follow operation precedence: brackets first, then multiplication (AND), then addition (OR).

  1. Separate the expression into terms/subexpressions.
  2. Implement complements with NOT gates.
  3. Implement products with AND gates.
  4. Implement sums with OR gates.
  5. Follow the same operation sequence as the expression.
Module example: X = A(BC + D̄). The slide labels the gate-building sequence to show how the expression becomes a circuit.

9. Logic Circuit → Boolean Expression

Follow the module's left-to-right rule: begin at the left-most inputs and derive the expression of each intermediate gate until reaching the final output.

Technique: Label every intermediate gate output. This prevents skipping a complement or bracket.

10. Boolean Expression → Truth Table

If there are x input variables, the number of possible input combinations is:

n = 2x

The module's construction method:

  1. Identify x and n.
  2. Find variable values that make the expression equal to 1.
  3. List all n input combinations and fill the output; all other outputs are 0.

The table-making tip in the slides is to list the input combinations as binary values from 0 to n−1.

11. Truth Table → Logic Circuit

The slides use output rows where X = 1 to obtain product terms. The product terms are then ORed to form the Boolean expression, after which the circuit is implemented.

  1. Find every truth-table row whose output is 1.
  2. Create the corresponding product term.
  3. OR all product terms together.
  4. Implement the resulting expression using logic gates.

12. Logic Circuit → Truth Table

The module gives two steps:

  1. Derive the Boolean expression of the circuit output.
  2. Use that Boolean expression to construct the truth table.

14. Practice + Model Answers

Q1. Simplify A + A.

Answer: A (Rule 5).

Q2. Simplify A·Ā.

Answer: 0 (Rule 8).

Q3. Simplify A + AB.

Answer: A (Rule 10).

Q4. Apply DeMorgan to overline(ABC).

Answer: Ā + B̄ + C̄.

Q5. Apply DeMorgan to overline(A+B+C).

Answer: ĀB̄C̄.

Q6. An expression has 4 input variables. How many truth-table rows?

Answer: 2⁴ = 16.

Q7. What direction should be followed when deriving an expression from a circuit?

Answer: Left to right, beginning with the left-most inputs and progressing to the final output.

15. Common Mistakes

  • Treating Boolean + as ordinary arithmetic instead of OR.
  • Forgetting that juxtaposition such as AB means AND.
  • Breaking a DeMorgan complement bar without changing AND ↔ OR.
  • Ignoring the scope/length of a complement bar.
  • Drawing a circuit in a different operation order from the Boolean expression.
  • Using the wrong number of truth-table rows; always calculate 2x.
  • When converting a truth table to an expression, accidentally using rows where output = 0 instead of the module's output-1 product-term method.

16. Final Exam Cheat Sheet

Swap: A+B=B+A, AB=BA
Regroup: A+(B+C)=(A+B)+C, A(BC)=(AB)C
Distribute: A(B+C)=AB+AC
Identity: A+0=A, A·1=A
Dominance: A+1=1, A·0=0
Idempotent: A+A=A, A·A=A
Complement: A+Ā=1, A·Ā=0
Double complement: Ā̄=A
Absorption: A+AB=A
DeMorgan: break bar + swap AND/OR
Truth table rows: 2x
Circuit → expression: left-to-right
