3. Basic Combinational Logic

The module lists four basic forms: AND-OR, AND-OR-Invert, XOR and XNOR. It also explains the design idea of choosing whether the final circuit output should be active HIGH (1) or active LOW (0).

Core module idea: Active-HIGH output can be implemented naturally with SOP / AND-OR logic. For an active-LOW output, the output can be inverted, producing AND-OR-Invert logic.

4. AND-OR Logic

An AND-OR circuit consists of any number of AND gates feeding an OR gate. The slide gives SOP such as AB + CD + EF as an example.

5. From Truth Table to AND-OR

The worked example in the module follows this flow:

  1. Use the truth table.
  2. Derive the Boolean expression / map the 1s to a K-Map.
  3. Simplify using K-Map.
  4. Implement the simplified expression using AND-OR logic.
Exam link with Module 4b: AND-OR is closely associated with an SOP result after K-Map simplification.

6. AND-OR-Invert Logic

The module describes AND-OR-Invert as the complemented AND-OR circuit. The result is the complement of the AND-OR output. DeMorgan's theorem connects this structure to POS.

Visual pattern: AND stage → OR stage → output inverter.

Exercise 5.1 and the self-test ask you to take a truth table and implement an active-low output using AND-OR-Invert logic, with the K-Map expression written as POS.

7. NAND and NOR Are Universal Gates

The module defines a universal gate as one that can be converted to perform the functions of basic gates, allowing it to implement logic circuits. The two universal gates covered are NAND and NOR.

Why use one gate type? The slides mention stocking one gate type, possible cost reduction when buying in volume, and reusing spare gates in an IC.

8. NAND as a Universal Logic Element

The slides demonstrate NAND configurations that act as NOT, AND, OR and NOR.

NAND → NOT: connect the NAND inputs together.
NAND → AND: NAND followed by NAND-as-inverter.
NAND → OR: use the NAND dual/negative-OR relationship shown in the module.

Exercise 5.2 asks you to implement individual expressions using NAND gates. Exercise 5.3 applies NAND implementation to X = AB + CD.

9. NOR as a Universal Logic Element

The module similarly demonstrates NOR configurations for NOT, OR, AND and NAND functions.

NOR → NOT: connect the NOR inputs together.
NOR → OR: NOR followed by NOR-as-inverter.
NOR → AND: use the NOR dual/negative-AND relationship shown in the slides.

Exercise 5.4 asks for NOR implementations of expressions including OR and AND functions.

10. Dual Symbols

The module introduces alternate symbols:

GateAlternate / dual interpretation
NANDNegative OR
NORNegative AND

The slide's conversion procedure is based on bubbles: put bubbles at the required input/output, change the gate symbol, and use bubble cancellation where two connected bubbles meet.

Important: A bubble represents inversion. Two bubbles at a connection can cancel. Do not add or remove a bubble without accounting for its logical effect.

11. SOP Circuit → NAND Only

The module gives this three-step procedure:

  1. Put bubbles at the inputs of the right-most OR gate.
  2. Compensate by adding bubbles at the outputs of the preceding AND gates.
  3. Replace the negative-OR symbol with the NAND symbol.
Fast exam rule: SOP naturally maps to a NAND–NAND implementation.

12. POS Circuit → NOR Only

The corresponding slide shows:

  1. Put bubbles at the inputs of the right-most AND gate.
  2. Compensate by adding bubbles at the outputs of the preceding OR gates.
  3. Replace the negative-AND symbol with the NOR symbol.
Fast exam rule: POS naturally maps to a NOR–NOR implementation.

14. Odd-Level / Even-Level Dual-Symbol Technique

The slides demonstrate dual-symbol replacement at selected gate levels. The main principle is to preserve the original logic by ensuring bubbles cancel correctly between connected stages.

Slide warning worth memorising: DE ≠ D + E. A bar/bubble changes the expression according to DeMorgan's theorem; do not simply replace multiplication with addition without the required complements.

15. Six Steps for Designing a Combinational Circuit

StepAction from the module
1Understand the problem to be solved.
2Convert the problem statement to a Boolean expression or truth table, whichever is more natural.
3Simplify the output using Boolean algebra, K-Map or another technique.
4Draw the circuit from the simplified output.
5Convert the simplified circuit to universal gates only: SOP → NAND only; POS → NOR only.
6Redraw the final circuit using dual symbols.

16. Step 1 Is the Most Critical

The module explicitly calls Step 1 the most critical stage. Determine:

  1. How many inputs exist and give each a variable name.
  2. How many outputs exist and give each a variable name. If there is more than one output, treat each output separately first and finally combine the circuits.
  3. The relationship between outputs and inputs.

18. How to Understand X = AB + AC + BC

AB = tanks A and B are low-level.
AC = tanks A and C are low-level.
BC = tanks B and C are low-level.

If any one of these pairs occurs, X becomes HIGH. When all three sensors are HIGH, the condition is also satisfied.

19. Multiple-Output Design

The module next gives a 3-input, 2-output problem with inputs A, B, C and outputs X, Y. For multiple outputs, each output should first go through the normal design process separately; the resulting circuits can then be combined.

Module example:
For binary input 0, 1 or 2 → output is one greater.
For input 3, 4, 5 or 6 → output is three less.
Input 7 never exists → treat it as don't care.

The slides map X and Y separately to K-Maps, simplify each output, draw each circuit and finally combine them.

22. Translating English into Boolean Logic

The final slide gives simple language-to-expression examples. The exam skill is to identify conditions joined by words such as AND, OR and NOT, assign variables, then write the Boolean relationship.

Suggested method: Circle OR → write +. Underline AND → write multiplication. Mark NOT → complement the relevant variable/expression.

23. Common Mistakes

  • Using AND-OR when the required final output is active LOW without accounting for inversion.
  • Forgetting that NAND and NOR are universal because they can reproduce the basic gate functions.
  • Converting SOP to NOR-only or POS to NAND-only when the module's direct implementation rule is SOP → NAND and POS → NOR.
  • Adding/removing bubbles in a dual-symbol circuit without compensating for the inversion.
  • Ignoring DeMorgan's theorem when reading alternate symbols.
  • Starting circuit design before clearly defining inputs, outputs and their relationship.
  • For multiple outputs, trying to simplify all outputs as one expression rather than handling each output separately first.
  • Ignoring a stated impossible input that should be treated as don't care.

24. Mini Quiz

Q1. Which form naturally maps to AND-OR logic?

Answer: SOP.

Q2. Which two gates are universal?

Answer: NAND and NOR.

Q3. What implementation is preferred for an SOP expression using one universal gate type?

Answer: NAND-only / NAND–NAND.

Q4. What implementation is preferred for POS?

Answer: NOR-only / NOR–NOR.

Q5. What should you determine first in a combinational-circuit word problem?

Answer: Inputs, outputs and the relationship between them.

Q6. Three-tank problem simplified output?

Answer: X = AB + AC + BC.

Q7. In a multiple-output problem, what should you do?

Answer: Design/simplify each output separately first, then combine the circuits.

Q8. What does a bubble indicate?

Answer: Logical inversion/complement.
